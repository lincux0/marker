# Marker.Tests

测试工程使用 MSTest，链接共享生产纯逻辑，当前覆盖：

- 快照来源、会话、版本、同版本重同步、未知字段与消息大小边界。
- CommonMark 基础语法、选定 GFM 扩展和原始 HTML 禁用。
- 受控长文解析完整性与耗时记录；不把解析耗时当作端到端延迟或 IME 性能。
- Unicode 快照容量、增量拒绝后的状态保留，以及保存/恢复往返。
- 编码、BOM、换行、磁盘冲突、恢复草稿、本地图片和激活路径安全。
- 设置数据库、迁移、事务回滚、窗口位置和外观规则。

在根目录运行 `./scripts/build.ps1` 完成固定依赖还原、构建和测试；局部重跑命令见[工程指南](../../docs/工程开发指南.md)。实际数量、权限跳过原因与结果见[建设历程](../../docs/progress.md)。这些测试不代替真实 WebView2、中文输入法、系统兼容或安装包验收。
