# 字体候选清单

2026-10-09，根据字体作者和厂商官方资料整理。以下是供选择的候选，尚未下载、安装或随 Marker 分发；用途与优先级是本项目的设计建议，不是流行度排名。

| 字体 | 建议用途 | 接入考虑与官方来源 |
|---|---|---|
| 思源宋体 | H1/H2、长文阅读；优先候选 | 多字重、简繁覆盖完整。采用 SIL OFL 1.1，适合附许可证随应用分发。[Adobe 产品介绍](https://source.typekit.com/source-han-serif/cn/)、[许可证](https://github.com/adobe-fonts/source-han-serif/blob/master/LICENSE.txt)。 |
| 思源黑体 | 清晰的正文、技术文档；优先候选 | 与思源宋体组成统一的宋黑搭配；采用 SIL OFL 1.1。[官方仓库](https://github.com/adobe-fonts/source-han-sans)、[许可证](https://github.com/adobe-fonts/source-han-sans/blob/master/LICENSE.txt)。 |
| 霞鹜文楷屏幕阅读版 | 随笔、笔记、阅读；优先候选 | 屏幕版增加笔画厚度并调整度量，更适合 PC 显示。SIL OFL 1.1；分发时附许可文本。[作者仓库](https://github.com/lxgw/LxgwWenKai-Screen)。 |
| 朱雀仿宋 | 传统风格正文、文史文档 | SIL OFL 1.1，当前官方版本仍有预发布标识；适合可选项，先检查缺字与中英文混排。[作者仓库](https://github.com/TrionesType/zhuque)。 |
| MiSans | 简洁现代正文 | 官方允许免费商用及嵌入，但软件须注明使用 MiSans、保留版权/许可，禁止改编；采用厂商许可，不是 OFL。[官方 FAQ](https://hyperos.mi.com/font/zh/faq/)、[许可协议](https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf)。 |
| OPPO Sans 4.0 | 现代正文、界面字体 | 官方允许免费商用，同时限制改编、售卖和另设下载渠道。先作为系统已安装字体候选；是否随开源安装包分发须明确满足厂商条款。[ColorOS 官方说明](https://www.coloros.com/article/A00000074/)。 |
| 方正小标宋 | 正式文档 H1/H2 | 用户指定的优先标题候选。官方区分个人桌面使用与 APP 嵌入授权；支持调用用户合法安装字体，随应用打包需取得对应授权。[官方产品页](https://www.foundertype.com/index.php/FontInfo/index/id/164)、[APP 嵌入授权](https://shop.foundertype.com/index.php/BuyAuth/empowerFonts/bid/62/codeType/GBK.html)。 |
| 方正书宋 | 正式文档正文 | 与方正小标宋搭配，属于官方基础字库清单；同样须区分系统字体调用与字体文件内嵌分发。[官方嵌入授权及基础字体清单](https://shop.foundertype.com/index.php/BuyAuth/empowerFonts/bid/62/codeType/GBK.html)。 |

建议第一批选择思源宋体、思源黑体和霞鹜文楷屏幕阅读版。方正小标宋可作为用户自行合法安装后的标题选项。后续正式接入时，确认准确 family 名、字体缺失回退、安装体积与版本许可，再更新设置模型、前后端白名单、SQLite 兼容测试及安装包；不能只增加下拉框标签。
