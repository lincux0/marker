- [阅读界面优化方案](阅读界面UI优化方案.md)与[阅读界面验收](阅读界面验收.md)：阶段计划和证据。

- [测试文档](测试文档.md)和[阅读样例](samples/u2-reading.md)：测试材料，不构成全量兼容承诺。
