# Marker 用户指南

本文描述当前实现。Marker 是单文档 Windows Markdown 编辑器；操作原始文档前建议保留独立备份，恢复草稿不能替代备份。

## 安装、升级与卸载

支持 Windows 11 24H2（build 26100）及以上的 x64 系统，需要 Microsoft Edge WebView2 Evergreen Runtime。缺失时应用或安装器会提示，不自动下载；获取入口见[工程指南](工程开发指南.md)。Windows 10、ARM64 和其他平台尚未验证或提供发行包。

Setup 默认安装到 `%LOCALAPPDATA%\Programs\Marker`，仅作用于当前用户。从开始菜单启动，或通过 Windows“打开方式”选择 Marker。安装会添加 `.md` / `.markdown` 候选项，不会修改既有默认应用；需要双击直接打开时，在 Windows 中明确选择始终使用 Marker。

下载后用 PowerShell `Get-FileHash -LiteralPath '<安装包路径>' -Algorithm SHA256` 核对发布者提供的 `.sha256`，同时核对来源与签名。哈希一致用于确认内容，并不等于受信任签名。当前开发产物未签名，MSIX 安装流程见工程指南。

升级前保存并关闭 Marker、备份重要文档及本地设置，再运行新 Setup；升级覆盖与所有目标系统兼容性仍需逐版本验收。通过 Windows 已安装应用或安装目录的卸载程序卸载。卸载保留用户 Markdown、设置和恢复草稿；请勿在未备份时清空数据目录。

## 编辑与阅读

用工具栏或 `Ctrl+N` 新建、`Ctrl+O` 打开文档。页面呈现常见 Markdown 样式，光标进入相关内容时可编辑原文。`Ctrl+Alt+M` 切换源码标记；复杂结构或显示不符合预期时，可打开标记检查源文。保存内容始终是 Markdown，不会将呈现效果转换为 HTML 文件。

源码模式切换会保留当前选区和页面位置。呈现模式下点击任务列表复选框也会留在原处。

支持常见标题、引用、列表、任务、表格、代码围栏、脚注、数学公式和提示框。提示框类型为 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION`。Mermaid 当前仅支持 `flowchart` / `graph` / `sequenceDiagram`；解析失败或超出限制时保留源文回退，不执行图表中的脚本。未知代码语言显示纯文本，高亮为词法呈现，不提供 IDE 诊断。

工具栏“大纲”列出标题，每页最多 200 项；点击定位，返回按钮恢复原选区和滚动。章节按钮可复制锚点，正文 `Ctrl+点击` 同页链接进行导航。成功加载的本地图片可用独立放大按钮进入灯箱，支持适配、原尺寸、`+` / `-` 缩放和 `Esc` 关闭。

`Ctrl+点击` 本地 Markdown 链接会打开目标文档，并保留未保存确认；其他受支持本地目标交给系统关联应用，危险程序或脚本扩展会被拒绝。HTTP(S) 链接在默认浏览器中打开。

专注模式临时收起可选按钮；设置 → 顶部栏可选择直显功能，其余进入“更多”。字数统计中文按字、英文按词，Markdown 标记和链接目标不计字数。详细统计口径及格式样例见[工程指南](工程开发指南.md)和[测试文档](测试文档.md)。

## 快捷键

以下命令在编辑器拥有焦点时使用；Windows 文件对话框及设置控件有各自键盘行为。

| 快捷键 | 操作 |
|---|---|
| `Ctrl+N` / `Ctrl+O` | 新建 / 打开 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 |
| `Ctrl+Alt+M` | 显示或隐藏源码标记 |
| `Ctrl+Enter` | 在当前行后新建段落 |
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体 |
| `Ctrl+K` | 链接 |
| `Ctrl+1` … `Ctrl+6` / `Ctrl+0` | 标题等级 / 普通段落 |

输入法组合未提交时，保存或相关命令可能被阻止；先完成选词，再保存。

## 保存、外部修改与恢复

- 打开支持严格 UTF-8（有/无 BOM）及带 BOM 的 UTF-16 LE/BE；其他内容可明确选择 GB18030。编辑期间统一 LF，保存恢复原编码、BOM 和换行元数据。混合换行询问使用 CRLF、LF 或取消。
- `Ctrl+S` 保存当前文件；未命名文档需先选路径。关闭或切换脏文档时，可保存、放弃或取消。保存使用同目录临时文件及原子替换，并检查磁盘内容指纹。
- 外部修改通知可“重新加载”或“关闭”。关闭只隐藏该版本通知，不取消冲突保护；重载有未保存编辑时须确认丢弃，取消或读取失败保留编辑。
- 保存冲突时，按提示重新载入、另存副本或取消；如竞态产生 `.external` 文件，应用显示实际路径，核对并备份后处理。
- 有恢复草稿时启动会提示，也可使用“恢复草稿”。恢复得到未命名副本，不自动写回原文件；人工核对后保存。突然终止仍可能丢失最近尚未落盘的编辑。

另存到不同目录不会复制或改写相对图片引用，可能导致图片失效。请一起迁移所需资源或手动调整源文。

## 本地数据与隐私

| 数据 | 当前路径或行为 |
|---|---|
| Markdown 文档 | 用户选择的文件位置 |
| 设置和窗口位置 | `%LOCALAPPDATA%\Marker\settings.db` |
| 恢复草稿 | `%LOCALAPPDATA%\Marker\Recovery`，包含正文及原路径 |
| WebView2 用户数据 | `%LOCALAPPDATA%\Marker\WebView2` |
| 旧设置 | `settings.json` 迁移后保留，后续使用数据库 |

备份设置前关闭 Marker，不要在运行时只复制正在写入的数据库。损坏或未知版本设置/草稿保留并限制覆盖，请先备份再处理。本地存储不代表加密；有访问用户目录权限的程序可能读取这些文件。

应用不要求账户或云同步。编辑器、公式和图表资源随包提供；文档页面拦截未授权网络资源，不加载远程图片。`https://editor.marker.example/` 与 `https://preview.marker.example/` 是映射到本地资源的虚拟地址。主动 `Ctrl+点击` HTTP(S) 链接会调用系统浏览器，该浏览器可能访问网络；WebView2 更新及平台行为由运行时自身管理。

反馈时使用脱敏最小文档，不要上传设置数据库、恢复草稿、真实用户路径或整个 WebView2 目录。

## 限制与排查

- 文件读写上限 8 MiB；文本还须同时满足 1 Mi UTF-16 单元及 2 MiB 完整 UTF-8 桥接快照预算。控制字符和 JSON 转义占用额外预算，文件小于 8 MiB 也可能无法打开。容量超限时用其他编辑器拆分。
- 本地图片仅允许当前文档目录内相对 PNG/JPEG/GIF/WebP/BMP，单张不超过 16 MiB；绝对路径、越界、重解析点及未授权资源会被拒绝。远程图片和 SVG 不支持。
- 文档超过 100,000 字符时代码高亮降级；复杂公式、图表另有大小/数量限制。超长文性能不作无条件保证。
- 编辑期呈现与 Markdig 解析存在差异，不保证所有 CommonMark/GFM 方言完全一致；原始 HTML 不作为可执行内容呈现。
- 没有多标签、文件树、图片粘贴管理、云同步、导出或打印。最低系统、混合 DPI 与长期使用仍有待验项，详见[建设历程](progress.md)。

无法启动时检查系统版本、WebView2 和完整程序目录；构建失败按工程指南核对固定 SDK/Node/npm 与锁文件。图片、容量或编码错误应保留原文，附脱敏复现与完整错误提交 Issue；安全问题按[安全政策](../SECURITY.md)私密报告。
