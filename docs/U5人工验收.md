# U5 中文输入法与 Narrator 验收

日期：2026-10-10。自动化、构建和安装证据见[阅读界面验收](阅读界面验收.md)。用户已于本日反馈人工验收完成，未发现阻断性 bug，可视为通过。中文输入法与 Narrator 按该反馈记为人工通过；未提供输入法名称及逐项播报记录，不补造细节。以下保留复验清单。

## 准备

使用当前仓库 Release EXE：`src/Marker.App/bin/x64/Release/net10.0-windows10.0.26100.0/win-x64/Marker.App.exe`。开始前结束本次测试残留的 Marker 进程；若普通关闭失败，可用任务管理器的管理员权限结束。避免同时开启多个测试实例。

新建临时文档测试输入，另打开 `docs/测试文档.md` 检查阅读和读屏。需要修改样例时先另存副本，保留仓库样例。

## 中文输入法

1. 记录输入法名称。在正文、标题、列表、引用、表格单元格和代码块内输入“中文输入测试，ABC 123。”，确认候选框位置正确，提交后无丢字、重字、乱码和跳行。
2. 在候选尚未确认时按 Esc 取消；重新输入并提交。分别尝试 Ctrl+S、代码模式、专注模式，确认组合输入不会被破坏；被保护的操作应有提示，完成候选后可正常操作。
3. 提交文字后切换代码模式，再切回正文；撤销、重做，确认文字与选区正确。另存临时 Markdown 并重新打开，确认中文和换行保留。

## Narrator

1. 用 Win+Ctrl+Enter 开启讲述人，先用 Tab/Shift+Tab 遍历工具栏、更多菜单、目录及搜索面板，确认能读出控件名称、展开/收起状态，焦点可见且不被裁切。
2. 打开目录，用键盘选择章节，再返回；检查标题层级和正文可读。不要把浏览器 DOM/ARIA 断言当作此步骤的通过证据。
3. 检查图片替代文本、代码复制、公式、脚注与提示框，记录实际播报内容。打开图片/图表放大框，用 Tab、缩放键和 Esc，确认关闭后回到触发控件，没有焦点困住或错误读序。
4. 检查通知和错误提示是否播报，专注模式仍有明确退出入口。完成后关闭讲述人和测试窗口。

混合 DPI、多屏、最低 Windows build 26100 和长期使用仍需对应设备验证，本轮不根据上述两项推定它们通过。
